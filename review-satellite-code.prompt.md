# Review Satellite Code Prompt

Create a reusable prompt for auditing the satellite ground station codebase.

## Description
Review this satellite ground station code for security, performance, reliability, and maintainability.

## Prompt

Review the satellite ground station code for:
- Security issues such as buffer overflows, unsafe input handling, and invalid data validation
- Performance issues such as UDP buffer sizes, database batching, and inefficient loops
- Reliability issues such as error handling, reconnection logic, and graceful shutdown
- Maintainability issues such as modularity, comments, type hints, and test coverage

Provide a concise report with findings, specific file references, and suggested improvements.

## Example Invocation

```
Review the satellite ground station project for security, performance, reliability, and maintainability issues.
```
